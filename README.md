# Unsupervised Learning using Python

This repository contains my hands-on implementations of various **Unsupervised Machine Learning algorithms** using Python and Scikit-Learn.

The notebooks cover clustering, dimensionality reduction, recommendation systems, and association rule mining with practical examples and visualizations.

---

## Repository Contents

### Clustering Algorithms

- K-Means Clustering
- Hierarchical Clustering
- DBSCAN Clustering

### Dimensionality Reduction

- Principal Component Analysis (PCA)
- t-SNE Visualization

### Recommendation System

- Real-Time Recommendation Engine

### Association Rule Mining

- Apriori Algorithm
- Market Basket Analysis

---

## Installation

Clone this repository:

```bash
git clone https://github.com/Pavithrag-ds/Unsupervised_Learning.git
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn mlxtend
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
